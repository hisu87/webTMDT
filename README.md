> 🌸 **webTMDT** là dự án web thương mại điện tử mẫu dành cho cửa hàng nước hoa, với đầy đủ tính năng quản lý sản phẩm, đơn hàng, người dùng và giao diện quản trị hiện đại.

---

## ✨ Tính năng nổi bật

- 🛍️ **Trưng bày sản phẩm** với ảnh, mô tả, phân loại
- ➕ **Thêm vào giỏ hàng**, đặt hàng & thanh toán nhanh chóng
- 🔐 **Đăng ký, đăng nhập** và quản lý tài khoản người dùng
- 🛠️ **Trang quản trị**: quản lý sản phẩm, đơn hàng, khách hàng
- 📱 **Giao diện responsive** cho mọi thiết bị
- 🚀 **Thông báo động** bằng SweetAlert2 (popup đẹp mắt)
- 🎨 **Dễ dàng tùy biến, mở rộng**

## 🚀 Bắt đầu sử dụng

1. **Clone dự án**
   ```sh
   git clone https://github.com/hisu87/webTMDT.git
   cd webTMDT
   ```

2. **Cài đặt phụ thuộc**
   - Nếu dùng Node.js:
     ```sh
     npm install
     # hoặc
     yarn install
     ```
   - Nếu dùng Java:
     - Import vào Eclipse/IntelliJ, resolve Maven/Gradle dependencies

3. **Khởi động ứng dụng**
   - Node.js: `npm start`
   - Java: Chạy trong IDE hoặc `mvn spring-boot:run` nếu dùng Spring Boot

> 🌸 **webTMDT** is a sample eCommerce website project for fragrance stores, packed with product, order, user management, and a modern admin dashboard.

---

## ✨ Main Features

- 🛍️ **Product showcase** with images, descriptions, and categories
- ➕ **Add to cart**, place orders & fast checkout
- 🔐 **User registration, login**, and account management
- 🛠️ **Admin dashboard**: manage products, orders, customers
- 📱 **Responsive UI** for all devices
- 🚀 **Dynamic notifications** using SweetAlert2 (beautiful popups)
- 🎨 **Easy to customize and extend**

---

```
perfume/
 ├── WebContent/

 │    │    └── ...         # Customer templates
 │    └── ...              # Static resources
 ├── src/                  # (If any) Backend source code
 └── ...                   # Configuration files
```

## 🚀 Getting Started

1. **Clone the repository**
   ```sh
   git clone https://github.com/hisu87/webTMDT.git
   cd webTMDT
   ```

2. **Install dependencies**
   - If using Node.js:
     ```sh
     npm install
     # or
     yarn install
     ```
   - If using Java:
     - Import into Eclipse/IntelliJ and resolve Maven/Gradle dependencies

3. **Run the application**
   - Node.js: `npm start`
   - Java: Run in IDE or `mvn spring-boot:run` if using Spring Boot
